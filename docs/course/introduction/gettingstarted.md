# Getting Started

Caught your attention? Welcome to the tutorial section.

## 📦 Installation

### Wally
> Add the following to your wally.init:

> ```luau
> Allure = "r-iva9/allure@1.1.0"
> ```

### From source
> Directly download the latest version `.rbxm` and place it in your replicated storage.
