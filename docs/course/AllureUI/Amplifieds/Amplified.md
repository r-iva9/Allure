# Amplified Tables

Now that we have covered the core of, pretty much, everything in Allure, we can move on to the actual powerful features it has to offer.
<br>Amplified Tables are a reactive extension to a standard table.

This massive concept carries a learning curve. But it's the power of UI on Allure.

---

If you've ever used neighbouring UI libraries, you've used `prop tables`.
<br>Prop tables are mounted on instances to apply data and business logic.

Allure reinvents the concept by decoupling `prop tables` entirely into an entire concept of state machinery.


Amplified Tables are interchangeable with states, because they share everything states have to offer.

## Amplifying a table

Let's create your first amplified.

```luau
local main = Allure:garbage {}

local myamplified = main:Amplify {}
```

At a first glance, amplifieds don't really differ from normal tables:

```luau
local myamplified = main:Amplify {
    value = 10
}

myamplified.text = "Hello world!"

print(myamplified.value, myamplified.text)  --10 Hello world!
```

So we'll begin from simple features added onto the table.

## `Allure.onSet`

Amplified Table is a State.

You can connect a function to an amplified just as you'd do it with a state, however, this connection is *global* to the table, this connection hook is called whenever any *key* is updated with *any* value:

```luau
myamplified:connect("anything")(function(self, key, value)
    print("Key", key, "changed to value", value)
end)

myamplified.text = "New"
myamplified.name = "Part"
```
::: code-group
```luau [Output]
Key text changed to value New
Key name changed to value Part
```
:::

To connect a function to the changes for a specific key, set a different key's value to a **Special Value** generated by `Allure.onSet`:

```luau
local myamplified = main:Amplify {
    value = 10,

    -- I didn't specify the key -- luau will assign this the key 1.
    Allure.onSet "value" (function(self)
        print("value changed to", self.value)
    end)
}

myamplified.value = 100
myamplified.text = "Hello"
```
::: code-group
```luau [Output]
value changed to 100
```
:::

## Reactivity of `Allure.onSet`

Amplifieds are not a frozen table.

We can literally reassign the `onSet` and remove it or change it!

```luau
local myamplified = main:Amplify {
    value = 10,

    onvalue = Allure.onSet "value" (function(self)
        print("value changed to", self.value)
    end)
}

myamplified.value = 100

-- Remove it!
myamplified.onvalue = nil
myamplified.value = 50

-- Add it again
myamplified.onvalue = Allure.onSet "value" (function(self)
    print("value changed to", self.value)
end)
myamplified.value = 25
```
::: code-group
```luau [Output]
value changed to 100
value changed to 25
```
:::

This reactivity spreads to changing any key, no matter if it was a state, onSet, or anything else.
<br>The amplified will update that key just as needed.

Are you starting to notice how powerful Amplifieds are?
<br>We discovered only a small bit out of what they have to offer.
